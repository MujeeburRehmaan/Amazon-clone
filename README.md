m# 🛒 Amazon Pakistan Clone

A frontend clone of Amazon Pakistan built using **HTML** and **CSS** only — no JavaScript frameworks or libraries required.

---

## 📌 About the Project

This project is a static replica of the Amazon Pakistan website, designed to practice and demonstrate core frontend development skills including layout design, responsive UI, and CSS styling techniques.

---

## 🚀 Features

- Amazon-style **navigation bar** with search bar and cart icon
- **Hero/banner section** with promotional content
- **Product cards** with image, title, and price layout
- **Footer** with multiple link columns (similar to Amazon's footer)
- Clean and structured **responsive design**

---

## 🛠️ Built With

| Technology | Purpose |
|------------|---------|
| HTML5 | Page structure and content |
| CSS3 | Styling, layout (Flexbox/Grid), and responsiveness |
